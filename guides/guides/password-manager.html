Fix reused passwords

⏱ 10 minutes to start 📱 iPhone and Android 🔧 One free app install

A single reused password means one breach anywhere becomes a breach everywhere. This is the highest-impact fix on the whole list, and it's free.

Why reused passwords are the biggest risk

When a company gets breached, the leaked passwords get tested against other sites automatically — this is called credential stuffing. If your email/password combination is reused anywhere else, that account is now exposed too, even if that second site was never breached itself.

You don't need to fix every account today. Start with email, banking, and anything tied to payment info — the rest can follow over the next few weeks.

Setting up a password manager

  1. Install a reputable free option — Bitwarden is open-source and free for personal use across unlimited devices
  2. Create one strong master password — this is the only password you'll need to remember from now on
  3. Install the browser extension or mobile app and sign in
  4. Start with your email account: go to its password settings, generate a new random password through the manager, and save it
  5. Repeat for banking, then anything storing a payment method
Write your master password down somewhere physical and secure — like a locked drawer — until you've fully memorized it. Losing access to a password manager with no recovery method locks you out of everything at once.

A realistic rollout

  • Today: email, banking, primary payment accounts
  • This week: anything with saved card details — shopping, subscriptions, delivery apps
  • Ongoing: every time you log into an old account, update it in passing rather than doing it all at once
